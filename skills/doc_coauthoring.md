# Document Co-Authoring Skill (`doc_coauthoring.md`)

This skill defines the guidelines for collaborative document creation, iterative drafting, back-and-forth review loops, and structured text co-authoring.

## Core Principles

1. **Iterative Feedback Loop**:
   - Never overwrite large document sections without explicit user confirmation or structured comment flags.
   - Present revisions in digestible blocks with clear rationale.

2. **Sectional Locking & Context Preservation**:
   - Maintain a master outline/table of contents.
   - When modifying a specific scene or chapter, keep surrounding plot beats and character voices intact.

3. **Line-Based Annotation Protocol**:
   - Support line-level comments (e.g. `#L14: Increase tension in narrator's dialogue`).
   - Parse line references precisely to execute targeted micro-edits rather than full text regenerations.

4. **Multi-Format Export**:
   - Support seamless export to Markdown (`.md`), Plain Text (`.txt`), and JSON formats for cross-platform compatibility.
