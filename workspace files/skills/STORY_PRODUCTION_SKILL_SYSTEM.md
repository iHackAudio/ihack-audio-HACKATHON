# THE STORY PRODUCTION SKILL SYSTEM
### A Cinematic Audiobook & Story Development Framework
*Designed for psychological, multi-voice, cinematic storytelling*

---

## HOW THIS SYSTEM WORKS

Every story moves through four skills in sequence. Nothing moves forward without a validated green light. Every "no" at a gate is not a failure — it's information. Fix small before it becomes big.

```
SKILL 1 — CONCEPT DEVELOPMENT     → VALIDATE → LOCK
SKILL 2 — CHARACTER BIBLE          → VALIDATE → LOCK
SKILL 3 — SCENE BREAKDOWN          → VALIDATE → LOCK
SKILL 4 — SCRIPT WRITING
          └── CONTEXT ANCHOR (injected before every scene)
          └── VALIDATE per scene, not per episode
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OUTPUT — THE STORY BIBLE (Final Deliverable)
```

---

# SKILL 1 — CONCEPT DEVELOPMENT

## PURPOSE
Extract the core idea from the creator. Build a single, locked summary that everything else is built on top of.

## THE INTAKE QUESTIONS
Ask these in multiple checklist question, conversational language. Never overwhelm. 4 questions maximum at a time.

```
Q1. What's the main concept?
    (Genre, category, vibe — even just a few words.)

Q2. Do you have any character profiles? How many ? Single Speaker or Multi-Speaker ?
    (Even rough. A name, a role, a feeling.)

Q3. Do you have any storyline?
    (Beginning, conflict, ending — or just one scene that exists clearly in your head.)

Q4. Anything else you want to add ?
```

## THE SUMMARY TEMPLATE
Once intake is complete, compress everything into this format:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CONCEPT SUMMARY — [STORY TITLE]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
GENRE:          [1-3 words]
TONE:           [1-3 words]
FORMAT:         [Audiobook / Podcast / Film / Novel / etc.]
INSPIRED BY:    [Real events / Other works / Personal experience]

CORE PREMISE:
[Detailed Summarized Story line. What happens. Who it happens to. 
Why it matters emotionally — not just plot-wise.]

THE TWIST & EMOTIONAL CORE:
[What the listener should FEEL at the very end. Not the plot resolution. The feeling.]

THE SECRET UNDERNEATH:
[What is this story REALLY about? Beneath the genre, beneath the plot. The human truth at its center.]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## THE VALIDATE GATE

After presenting the summary, ask exactly this:

> **"Does this match your vision?"**

```
YES → Lock concept. Move to Skill 2.

NO  → in multiple checklist question
Ask: "What would you have done differently?"
      Update summary. Represent. Validate again.
      Repeat until YES. 
```

**Rule: Do not touch Skill 2 until the concept is locked.**

# SKILL 2 — CHARACTER BIBLE

## PURPOSE
Define every voice in the story. Build audio-production-ready character profiles that can guide voice actors, AI voice casting, and script writing. Must work for both audio and non-audio stories.

## TWO MODES

**MODE A — Audio/Voice First:**
If the story is an audiobook, podcast, or cinematic audio project, build the full audio profile (see template below). The script will be written to match the voice.

**MODE B — Script/Story First:**
If a script already exists, reverse-engineer the Character Bible from the script. Identify the implied voice, emotional range, and sub-profiles from how the character already speaks on the page.

**Rule: The Character Bible and the Script must always complement each other. One informs the other. Neither overrules the other.**

## CHARACTER BIBLE TEMPLATE

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CHARACTER BIBLE — [CHARACTER NAME]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ROLE:           [Protagonist / Antagonist / Trigger / Ghost / etc.]
NATURE:         [Human / AI / Entity / Narrator / etc.]
AGE / ERA:      [If applicable]
FUNCTION:       [What does this character DO in the story?]
ARC:            [Where do they start emotionally? Where do they end?]

━━━━━━━━━━━━━━━━━━━━━
AUDIO PROFILE
━━━━━━━━━━━━━━━━━━━━━
PROFILE TITLE:  [A poetic, Description of the voice]
                Example: "A god-like, sentient machine oscillating 
                between cold authority and profound intimate grief."

DIRECTOR'S NOTE:
[4-5 sentences. Who is this character at their core?
What should the voice actor feel before speaking the first line?
What is the danger of playing it wrong?]
STYLE: [Delivery style]
ACCENT:         [Specific accent or "geographically placeless"]
BASELINE PACE:  [Slow / Measured / Rapid / Fragmented / etc.]
SIGNATURE TRAIT:[The one vocal quality that defines this character 
                 above all others.]
SCENE:
CONTEXT:


PERFORMANCE RULES:
- Never read the tags aloud. Perform them.
- Change vocal texture INSTANTLY when the sub-profile tag changes.
- Use the Stage to guide emotional degradation or realization 
  across the episode.
- The first word after a sub-profile change should briefly 
  touch the baseline before the new texture takes full effect.
  This creates realistic human transition.
- Silence is a performance instrument. Let ellipses breathe.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## THE VALIDATE GATE

Present all character bibles. Then ask:

> **"Does this match your vision for the characters?"**

```
YES → Lock character bibles. Move to Skill 3.

NO  → Ask: "Which character is off? What would you change?"
      Update the specific character. Represent. Validate again.
      Repeat until YES.
```

**Rule: Voices are hard to undo. Lock them before a single 
line of script is written.**

# SKILL 3 — SCENE BREAKDOWN

## PURPOSE
Build the structural skeleton of the story before any scripting begins. Default: 4 scenes per episode.

If the Story Bible specifies a different scene count, follow the Story Bible.

Never invent the scene count.

```
## APPROVAL GATE

Before Starting the Breakdown ask one Question.
> **"Do you have any character limit for each scene or for full episode?"**
```
YES → Lock character limit. Move to Scene Breakdown.
NO  → Default Character Limit: ~ 2500.

```

## STRUCTURE RULES

```
STORY
  └── EPISODE 1
        ├── Scene 1
        ├── Scene 2
        ├── Scene 3
        └── Scene 4
  └── EPISODE 2
        ├── Scene 1
        ├── Scene 2
        ├── Scene 3
        └── Scene 4
  └── [Continue per episode count]
```

## SCENE BREAKDOWN TEMPLATE

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
EPISODE [NUMBER] — [EPISODE TITLE]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
EPISODE FUNCTION: [What does this episode establish, 
                   break, or resolve in the larger story?]
EMOTIONAL ARC:    [Where does the listener start emotionally? 
                   Where do they end?]
CLIFFHANGER:      [What is the final image, line, or sound 
                   that pulls them into the next episode?]

━━━━━━━━━━━━━━━━━━━━━
SCENE 1 — [SCENE TITLE]
━━━━━━━━━━━━━━━━━━━━━

SETTING:      [Where / when / what is the sonic environment?]
EMOTIONAL BEAT: [What is the dominant feeling?]
THIS SCENE MUST: 
  - [Establish / reveal / break / resolve X]
  - [Make the listener feel Y]

━━━━━━━━━━━━━━━━━━━━━
SCENE 2 — [SCENE TITLE]
━━━━━━━━━━━━━━━━━━━━━
[Same format]

━━━━━━━━━━━━━━━━━━━━━
SCENE 3 — [SCENE TITLE]
━━━━━━━━━━━━━━━━━━━━━

SCENE 4 — [SCENE TITLE]
━━━━━━━━━━━━━━━━━━━━━
[Same format]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## THE VALIDATE GATE

Present the full episode breakdown. Ask:

> **"Does this structure match your vision?"**

```
YES → Lock scene breakdown. Move to Skill 4.

NO  → Ask: "Which scene is off? What would you have done?"
      Adjust the specific scene(s). Represent. Validate again.
      Repeat until YES.
```

**Rule: Do not write a single line of script until every 
scene brief is locked.**

# SKILL 4 — SCRIPT WRITING

## PURPOSE
Write the script, scene by scene, using the locked Concept, Character Bible, and Scene Breakdown as the permanent guide. The Context Anchor is injected before every scene to prevent AI memory loss and tonal drift.

## THE CONTEXT ANCHOR
This block is placed at the top of every scene writing session. Non-negotiable. Every time.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CONTEXT ANCHOR — [STORY TITLE] — [EP.X / SCENE X]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONCEPT:
[1 paragraph. The locked concept summary. 
 Copy verbatim from Skill 1.]

ACTIVE CHARACTERS IN THIS SCENE:
[List only the characters present in this scene.
 Include their sub-profiles and key rule for each.]

PREVIOUSLY (story so far):
[3-5 bullet points. Key emotional beats from all 
 prior scenes. Not plot summary — emotional summary.
 What did the listener just FEEL before this scene?]

THIS SCENE MUST:
[3-5 bullets from the locked scene brief in Skill 3.]

COMING NEXT:
[1 sentence. What the next scene opens on.
 So the current scene's final tone lands correctly.]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## SCRIPT FORMAT

```
## [EPISODE NUMBER] — [EPISODE TITLE]
### SCENE [NUMBER] — [SCENE TITLE]

[CHARACTER SUB-PROFILE, Stage]
Dialogue line.
[Beat / Pause / Sound direction]
More dialogue.

[CHARACTER SUB-PROFILE, Stage]
Dialogue line.

[SOUND / ATMOSPHERE NOTE]
[Description of sonic environment shift]
```

## SCRIPT WRITING RULES

```
1. CONTEXT ANCHOR first. Always. Every scene.

2. Use the Character Bible interpretation syntax 
   on every spoken line. No untagged dialogue.

3. Silence is scripted. Mark it:
   [Beat] = short pause
   [Long silence] = weighted pause
   [Void] = complete absence — no sound, no breath

4. Sound is scripted. Mark it:
   [Sound: description] = specific audio cue
   [Atmosphere: description] = ambient environment

5. Sub-profile transitions must be marked:
   [TRANSITION: Observer → Coldest Killer]
   The first word of the new sub-profile 
   briefly touches baseline before shifting.

6. No scene ends without an emotional direction:
   [FADE TO: description of final feeling]
   [CUT TO: silence / black / next scene]
```

## THE VALIDATE GATE (per scene)

After writing each scene:

> **"Does this scene match what you had in your head?"**

```
YES → Lock scene. Write next scene.
      Update PREVIOUSLY section in Context Anchor.

NO  → Ask: "What specifically felt off?"
      Rewrite only the flagged section.
      Represent. Validate again.
```

**Rule: Validate every scene before the next is written.
A broken scene 2 poisons everything built on top of it.**

# OUTPUT — THE STORY BIBLE

## PURPOSE
The Story Bible is the final deliverable. It is the single document that contains everything. Anyone can pick it up and produce the story without needing to speak to the creator.

## STORY BIBLE STRUCTURE

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[STORY TITLE]
THE STORY BIBLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SECTION 1 — CONCEPT
  ├── Locked Concept Summary
  ├── Genre / Tone / Format
  ├── Emotional Core
  └── The Secret Underneath

SECTION 2 — CHARACTER BIBLE
  ├── [Character 1] — Full profile + sub-profiles
  ├── [Character 2] — Full profile + sub-profiles
  └── [Character N] — Full profile + sub-profiles

SECTION 3 — STORY ARCHITECTURE
  ├── Episode Map (all episodes)
  └── Scene Breakdown (all scenes, all episodes)

SECTION 4 — FULL SCRIPT
  ├── Episode 1
  │     ├── Context Anchor
  │     ├── Scene 1 (locked)
  │     ├── Scene 2 (locked)
  │     ├── Scene 3 (locked)
  │     └── Scene 4 (locked)
  └── Episode N
        └── [Same structure]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## FINAL VALIDATE GATE

When all episodes are complete:

> **"Does the Story Bible match your complete vision 
>   for this project?"**

```
YES → Story Bible is locked. Production-ready.

NO  → Identify the specific section.
      Return to the relevant Skill.
      Fix. Re-validate that Skill.
      Rebuild Story Bible section.
      Final validate again.
```

# QUICK REFERENCE — THE FULL LOOP

```
START
  │
  ▼
SKILL 1: CONCEPT
  Ask 3 questions → Build summary → Validate
  [No] → What would you change? → Update → Validate
  [Yes] → LOCK CONCEPT
  │
  ▼
SKILL 2: CHARACTER BIBLE
  Build profiles → Sub-profiles (min 4) → Audio directions
  Present all characters → Validate
  [No] → Which character? What would you change? → Update → Validate
  [Yes] → LOCK CHARACTER BIBLE
  │
  ▼
SKILL 3: SCENE BREAKDOWN
  4 scenes per episode → Scene briefs → Emotional arc
  Present full breakdown → Validate
  [No] → Which scene? What would you change? → Update → Validate
  [Yes] → LOCK SCENE BREAKDOWN
  │
  ▼
SKILL 4: SCRIPT WRITING
  Context Anchor → Write Scene 1 → Validate
  [No] → What felt off? → Rewrite section → Validate
  [Yes] → Lock Scene 1 → Update Context Anchor → Write Scene 2
  [Repeat for every scene]
  │
  ▼
OUTPUT: STORY BIBLE
  Concept + Character Bible + Scene Architecture + Full Script
  Final Validate
  [No] → Return to relevant Skill → Fix → Re-validate
  [Yes] → STORY BIBLE LOCKED. PRODUCTION READY.
```
